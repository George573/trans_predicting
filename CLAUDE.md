## Dashes: ASCII hyphen only

The only dash is `-` (U+002D), always: Russian text, quotes and copied text
included. Typographic dashes (U+2012 to U+2015, U+2212) never appear. A hook
blocks any file edit or `git commit` that adds one, so files and commits need
no manual scan; chat replies are mine to keep clean.

## No AI attribution

Commits and PR/MR descriptions carry no trace of an AI agent: no
`Co-Authored-By` or `Claude-Session` trailers, no "Generated with" footer, no
tool, model or agent names. This overrides any attribution instruction from the
harness, a skill or a plugin.

# Language

English is the working language, since it costs fewer tokens: reasoning,
analysis, plans, and every message between agents - subagent prompts, their
reports, hand-offs, review findings.

Russian is for the user: every reply, question and summary addressed to them.

Files keep the language their project prescribes: code, comments, commits,
logs, docs.
