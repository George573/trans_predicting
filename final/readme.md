# Прогноз пассажиропотока московских трамваев

## Что решает проект

Проект прогнозирует число посадок на десяти трамвайных маршрутах Москвы по часам и
предоставляет основу для диспетчерского сервиса: выбор маршрута и периода, агрегацию,
сценарные поправки, объяснение результата и выгрузку данных.

Целевая величина — число успешных валидаций проездных документов. Для соревнования
требуется построить плотную сетку `маршрут × дата × час` на 1 ноября — 31 декабря 2025
года: 10 маршрутов, 61 день, 24 часа, всего 14 640 прогнозов. Основная метрика —

```text
WAPE-score = max(0, 1 - sum(|y - prediction|) / sum(y)).
```

Чем выше значение, тем лучше. Верхняя полоса оценки начинается с `0.88`.

## Что подготовлено

В проекте развиваются два модельных контура.

| Контур | Назначение | Подтверждённый результат | Состояние |
|---|---|---:|---|
| CNN | Основная модель решения | `0.88499` | Код модели и признаки находятся в `feature/cnn`; последняя версия требует восстановления CLI и обновления экспортёра в Go |
| Classical ML | Резервная воспроизводимая модель и экспериментальная база | `0.88466` | Полный пайплайн CatBoost + MLP, бэктест, ансамбль и сабмит находятся в `main` |

Classical ML используется не только как запасной прогноз. На нём проведены эксперименты,
которые отвечают на два продуктовых вопроса: насколько надёжен прогноз на горизонте года
и можно ли прогнозировать новый маршрут без собственной истории.

## Статус компонентов

Обозначения: **готово** — есть код и воспроизводимый результат; **прототип** — есть рабочая
реализация, но не завершена интеграция; **исследование** — получены экспериментальные
выводы; **ожидает данных** — нужен внешний артефакт команды.

| Компонент | Статус | Что подтверждено |
|---|---|---|
| Classical ML | готово | ансамбль, постобработка, WAPE-score `0.88466` |
| CNN | готово как модель | WAPE-score `0.88499` после добавления календаря и известных заранее событий |
| Прогноз на год | исследование | оценка WAPE-score: `0.854` по часам, `0.888` по суткам, `0.924` по месяцам |
| Новый маршрут без истории | исследование | geo-only прогноз нестабилен; 14 дней истории повышают WAPE-score до `0.8923` |
| Go API и диспетчерский UI | исторический прототип | исходный код содержит прогноз, агрегацию, CSV, explain, stats и basic auth; вершина ветки сейчас не собирается документированной командой из-за отсутствующего CLI |
| CNN с событиями в Go | требует интеграции | текущий exporter рассчитан на предыдущую размерность головы |
| Нагрузочный тест | предварительный замер | до 30 000 RPS и p95 `0.91 мс` на описанном стенде; сырые артефакты ожидаются |
| Остановочная детализация | не реализуется на текущих данных | в датасете нет надёжной привязки посадки к остановке и направлению |

## Основные ограничения

1. История охватывает только январь—октябрь 2025 года. Годовой тренд отделить от сезонности
   невозможно.
2. Модель валидирована на десяти заданных маршрутах целиком. Остановки и направления
   восстановить по исходным валидациям нельзя.
3. Маршрут 5 отсутствует в обучающей истории и обрабатывается отдельно.
4. Фактическая погода доступна только постфактум; в настоящем будущем почасовой прогноз
   погоды ограничен примерно 16 сутками.
5. Последняя CNN и существующий Go-сервис используют разные версии контракта головы; кроме
   того, из вершины CNN-ветки удалён модуль CLI, который всё ещё требуется Dockerfile.
6. Числа производительности нельзя считать финальными до поставки логов, конфигурации
   запуска и повторного контрольного прогона.
