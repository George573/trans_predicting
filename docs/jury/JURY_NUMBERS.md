# Цифры для жюри: производительность и качество прогноза

Все цифры получены на коде и артефактах репозитория. Графики лежат рядом в этой папке.

## Производительность API

Сервис на Go: на каждый запрос строит календарные признаки, вызывает CatBoost cyclic
(625 деревьев, `libcatboostmodel`) и возвращает прогноз. Кэша нет, модель считается в
каждом запросе.

**Стенд:** Linux arm64 (Ubuntu 22.04) в виртуальной машине на Apple Silicon, 4 vCPU, 3.9 ГБ RAM.
- 2 vCPU: сервис закреплён на ядрах 0-1 (`taskset`, `GOMAXPROCS=2`), генератор нагрузки на ядрах 2-3.
- 4 vCPU: сервис на всех ядрах, генератор делит с ним те же ядра, поэтому цифры 4 vCPU занижены.

Нагрузка open-loop: запросы уходят по расписанию, задержка считается от запланированного
момента. Каждая точка - 12 секунд.

**Смесь запросов как у диспетчера:** 60% "маршрут за день по часам", 20% "все маршруты за день
по часам", 15% "маршрут за 30 дней по дням", 5% "все маршруты за 30 дней по часам".
В среднем около 540 строк модели на запрос.

CPU - загрузка процесса сервиса, 100% = одно ядро.

## Качество прогноза

Метрика - WAPE-score = 1 - сумма|y - ŷ| / сумма y, по сетке маршрут × дата × час.
Прогнозы честные out-of-fold: модель обучена по край фолда и период валидации не видела.

| Модель | Фолд 3 (сен-окт, обучение по 31.08) | Фолд 4 (окт, обучение по 30.09) | Оба фолда |
|---|---:|---:|---:|
| Гармоническая регрессия | 0.874 | 0.873 | 0.874 |
| CatBoost base | 0.874 | 0.895 | 0.881 |
| MLP | 0.883 | 0.884 | 0.883 |
| **CatBoost cyclic** | 0.882 | **0.901** | 0.888 |
| 0.7 CatBoost cyclic + 0.3 MLP | 0.884 | 0.899 | **0.889** |

Порог максимального балла по критерию 1 - 0.88.

### Прогноз против факта, октябрь

- По часам - WAPE-score 0.901, по дням - 0.955.
- Модель на 4.4% занижает уровень октября: сумма прогноза 95.6% от факта, по будням 95.7%, по
  выходным 95.1%. Форма недели и суточный профиль совпадают. Уровень поправляет калибровка по
  маршрутам и дням недели в пайплайне сабмита, эти графики её не включают.
- Маршрут 17 за неделю 13-19 октября по часам: WAPE-score 0.914.
