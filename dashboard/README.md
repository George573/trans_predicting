# Дашборд прогноза посадок

Рабочее место диспетчера по [спецификации фронтенда](../docs/SPEC-frontend.md).
Формат запросов и ответов задаёт [OpenAPI](../api/openapi.yaml). Скриншоты в
`docs/design/` показывают композицию, но их числа, подписи и функции не считаются
требованиями. Локальная рабочая спека и задачи лежат в `.scratch/frontend-dashboard/`
по правилам `AGENTS.md`.

## Обязательный стек

| Задача | Библиотеки | Правило использования |
| --- | --- | --- |
| Приложение | React 19, TypeScript, Vite, React Router | SPA собирается в `dist`; в продакшене статику отдаёт Go-сервис. |
| Интерфейс | `@mantine/core`, `@mantine/hooks` | Одна тёмная тема; весь видимый текст по-русски. |
| Графики | **`@mantine/charts`** | Основные временные ряды и столбцы делаем через Mantine Charts. `recharts` - его зависимость, прямое использование для основных графиков не планируется. Матрицы и календарь могут быть обычной разметкой. |
| Даты | `@mantine/dates`, `dayjs` | Выбор периода; даты запроса остаются строками `YYYY-MM-DD`, диапазон ограничен областью из контракта. |
| Карта | `leaflet`, `@types/leaflet` | Локальный GeoJSON обязателен; тайлы OSM только дополнение. |
| Запросы | `openapi-fetch`, `openapi-react-query`, `@tanstack/react-query` | Типизированный клиент из OpenAPI. Основной прогноз запрашивается при изменении параметров, без долгого кэширования; Query хранит справочники и метаданные. |
| Контракт | `openapi-typescript` | Типы генерируются командой `pnpm api`; формы ответов вручную не дублируются. |

`@hookform/resolvers`, `zod`, `@siberiacancode/reactuse` и `clsx` уже есть в
каркасе, но обязательными для реализации не считаются. Для состояния запроса
используем `useReducer`, как требует спека. Новую библиотеку добавляем только
под конкретный экран или поведение.

## Локальный запуск

```sh
pnpm install
pnpm api
pnpm dev
```

`VITE_API_URL` нужен только если API запущен на другом origin. В общей поставке
используется тот же origin. Сейчас в репозитории есть только каркас интерфейса;
примеры ответов для разработки лежат в `../api/examples/`.
