# Погода 2025: Москва и Московская область

Собрано скриптом `../collect_weather.py` (только стандартная библиотека Python):

    python collect_weather.py                  # все источники
    python collect_weather.py rp5 gismeteo     # выборочно: era5, forecasts, meteostat, nasa, rp5, gismeteo

Время во всех почасовых файлах московское (UTC+3), колонка `time_msk`.

## Файлы

| Файл | Тип | Источник | Шаг | Точки |
|---|---|---|---|---|
| `fact_open_meteo_era5.csv` | факт (реанализ) | ECMWF ERA5 через Open-Meteo Archive API | 1 ч | 16 |
| `fact_meteostat.csv` | факт (станции) | Meteostat: METAR/ISD аэропортов и сводки ВДНХ | 1 ч (ВДНХ 3 ч) | 5 |
| `fact_nasa_power.csv` | факт (реанализ MERRA-2) | NASA POWER | 1 ч | 16 |
| `fact_rp5_synop.csv` | факт (станции Росгидромета) | rp5.ru, сводки SYNOP | 3 ч | 12 станций |
| `fact_gismeteo_monthly.csv` | факт, помесячно | страница архива Gismeteo | месяц | 13 городов |
| `forecast_ecmwf_day1.csv` | прогноз на сутки вперёд | ECMWF IFS 0.25° через Open-Meteo Previous Runs API | 1 ч | 16 |
| `forecast_icon_day1.csv` | прогноз на сутки вперёд | DWD ICON через Open-Meteo Previous Runs API | 1 ч | 16 |
| `forecast_gfs_day1.csv` | прогноз на сутки вперёд | NOAA GFS через Open-Meteo Previous Runs API | 1 ч | 16 |

Прогноз `day1` - значение, которое модель выдала примерно за 24 часа до указанного времени.
Его можно сравнивать с фактом построчно по `location` и `time_msk`.

## Общие колонки почасовых файлов

`location, lat, lon, time_msk, temperature_c, humidity_pct, precipitation_mm, pressure_hpa, wind_speed_ms, wind_dir_deg, cloud_cover_pct`

- `pressure_hpa` - давление, приведённое к уровню моря.
- `wind_dir_deg` - откуда дует ветер, 0 = север, 90 = восток.
- Пустая ячейка - значения нет.

## Особенности источников

- **ERA5, NASA POWER и прогнозы** - значения в узлах сетки моделей (ERA5 около 25 км, NASA около 50 км), а не на самой станции.
- **NASA POWER** не отдаёт давление на уровне моря и облачность по часам: есть только `surface_pressure_hpa` (давление на высоте поверхности).
- **Meteostat** закрывает пропуски наблюдений модельными прогнозами (`dwd_mosmix`, `metno_forecast`). По станциям области (Клин, Кашира и др.) за 2025 год там только модель, на ВДНХ модель занимает 2/3 часов, осадки модельные везде. Скрипт выбрасывает модельные значения по каждому параметру отдельно, поэтому в файле остались только наблюдения: Шереметьево, Внуково, Домодедово, Жуковский (почти каждый час) и ВДНХ (каждые 3 часа), без осадков. Колонка `temp_source` - откуда взята температура (`metar`, `isd_lite`, `dwd_poi`). Облачность пересчитана из окт в проценты, ветер из км/ч в м/с.
- **rp5**: 8 сроков в сутки. Осадки `precipitation_mm` - сумма за предыдущие `precipitation_period_h` часов (обычно 12 ч в сроки 06 и 18 UTC), в остальные сроки пусто. Облачность - нижняя граница интервала из сводки ("20-30%" -> 20). Давление пересчитано из мм рт. ст. в гПа. Колонка `weather` - текст явлений погоды из сводки. При использовании данных rp5 просит указывать сайт "Расписание Погоды", rp5.ru.
- **Gismeteo** за 2025 год отдаёт только помесячную сводку: максимум и минимум температуры, средний ветер и порывы, высоту снега, УФ-индекс. Подневного и почасового архива у Gismeteo больше нет, старый "дневник погоды" перенаправляет на эту сводку.

## Что не вошло

- **Яндекс Погода**: архив фактической погоды и архив прогнозов (с 2022 года) продаются, 7 440 руб. за выгрузку по одной точке. Бесплатный тестовый тариф API даёт только прогноз на 7 дней вперёд, прошлые даты недоступны.
- **Gismeteo API** (docs.gismeteo.net) - только текущая погода и прогноз, по токену.
