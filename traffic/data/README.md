# Трафик 2025: Москва и Московская область

Собрано скриптом `../collect_traffic.py`:

    python collect_traffic.py                          # все источники, кроме parking нужен pandas
    python collect_traffic.py telegram gibdd           # выборочно: yandex, telegram, gibdd, datamos, parking
    uv run --with pandas --with pyarrow python collect_traffic.py parking

Источник `parking` читает parquet, поэтому ему нужны `pandas` и `pyarrow`, остальным хватает стандартной библиотеки.
Полный сбор занимает около 15 минут: Telegram, ГИБДД и Wayback Machine опрашиваются с паузами.
Проверка разбора постов: `python test_collect_traffic.py`.

Время везде московское, колонка `time_msk`.

## Главное

Почасового архива пробок за 2025 год в открытом доступе нет ни у Яндекса, ни у TomTom, ни у городских служб.
Поэтому трафик собран из нескольких неполных, но проверяемых источников: у каждого есть ссылка ниже, а у каждого замера балла - ссылка на конкретный пост или снимок.

## Особенности источников

- **Яндекс Пробки.** Живой фид `https://core-jams-info.maps.yandex.net/info?format=json` отдаёт текущий балл Москвы, но не историю. За 2025 год есть только копии, которые случайно сохранил Wayback Machine: 227 замеров, в среднем 1-2 в день, провалы до двух недель (конец октября - ноябрь почти пуст). Пиковые часы попадают редко, максимум в архиве 6 баллов. Балла по Московской области у Яндекса нет.
- **ЦОДД (Москва).** Дептранс пишет балл, когда считает нужным, чаще днём и в плохие дни, поэтому ряд неравномерный: 2 поста в январе, 105 в декабре. Шкала своя, 0-10, с Яндексом на 12 замерах в пределах часа расходится не больше чем на 2 балла. `forecast_score` - прогноз из того же поста ("вечером ожидается до 8 баллов"). `avg_speed_kmh` есть у половины постов.
- **ЦБДД МО.** Каждый рабочий день около 09:00 пост с баллом по области и числом машин на дорогах МО в 08:50-08:55, около 18:00 пост с вечерним баллом. `vehicles_vs_prev_month_pct` - изменение к среднему прошлого месяца, как в посте. Числа переписаны из постов без правок, изредка в них бывают опечатки (1 411 725 машин 24.07.2025).
- **Парковки.** Первичный источник - городской сервис парковок, архив ведёт автор набора на Hugging Face. 39 парковок с "вечно полной" загрузкой (датчик не передаёт данные) выброшены. Замеры раз в полчаса усреднены до часа. Данных за январь-март 2025 нет.
- **ГИБДД.** В официальную статистику попадают только ДТП с пострадавшими. `traffic_change` показывает, перекрывалось ли движение (частично - 3 971 раз, полностью - 31). `tram_involved = 1` - в ДТП участвовал трамвай (81 случай в Москве).
- **Посты Дептранса.** Теги поставлены по ключевым словам и нужны только для фильтра, текст поста сохранён целиком. У ответов на посты взят собственный текст, без цитаты. Постов с тегом `tram` 276, многие называют маршруты из датасета, например "задерживаются трамваи № 11, 17 и 25".
- **Ремонты.** Статус работ в наборе не обновляется (507 объектов "не начаты"), надёжнее фактические даты `actual_begin` и `actual_end`.
- **Пассажиропоток по видам транспорта.** Наши 10 маршрутов стабильно дают 32-35% месячного пассажиропотока трамвая Москвы (январь-октябрь 2025), а в наборе есть и ноябрь с декабрём: 19,34 и 21,26 млн. Этим можно откалибровать месячный уровень прогноза. В январе 2025 у метро в наборе ошибка: 17,3 млн вместо примерно 173 млн.
- **data.mos.ru** выгружается без ключа через внутренний API сайта (`/api/v2/odataExports`), тот же, что у кнопки "Скачать".

## Проверка эффекта

`uv run --with pandas python check_effect.py` сравнивает отклонения пассажиропотока от обычного для того же дня недели и часа (медиана за соседние ±1-2 недели, без праздников) с отклонениями трафика:

| Показатель | n | Корреляция (Пирсон / Спирмен) |
|---|---|---|
| Москва: балл Яндекс Пробок, по часам | 122 | +0.19 / +0.14 |
| Москва: ДТП за день | 284 | +0.13 / +0.17 |
| МО: машин на дорогах в 08:55 | 201 | +0.10 / +0.12 |
| МО: утренний балл | 201 | +0.10 / +0.09 |
| Москва: максимальный балл ЦОДД за день | 110 | +0.08 / +0.08 |
| Москва: загрузка парковок, по часам | 3 297 | -0.01 / -0.02 |

Связь с загруженностью дорог слабая и положительная: в дни с пробками и авариями на трамвае ездят чуть больше.
Сильный эффект дают посты о задержках трамваев: в 3 часа после поста "задерживаются трамваи № ..." пассажиропоток названного маршрута составляет 0.79 от обычного по медиане и 0.71 в среднем (38 случаев), тогда как в целом по всем часам он 1.00.
Такие часы стоит помечать признаком или исключать из обучения как аномалии.

## Что не вошло

- **TomTom Traffic Index** убрал Москву из рейтинга в 2023 году. Эндпоинт `https://www.tomtom.com/traffic-index/api/live-traffic.json?city=RUS_moscow` работает, но отдаёт только последние 7 дней по часам. Исторический Traffic Stats API - только пробный доступ на 30 дней с регистрацией.
- **INRIX, HERE, Citymapper, Moovit** - Москвы в 2025 году нет или проект закрыт.
- **trafficindex.org** - дневные ряды по Москве только по платной подписке, бесплатно лишь годовое значение.
- **Перекрытия с data.mos.ru** (набор 2527) - набор перестал пополняться, все записи начаты в 2024 году или раньше.
- **Карта перекрытий transport.mos.ru** показывает только текущие перекрытия, завершённые исчезают.
- **Московская область**: mosreg.ru и mtdi.mosreg.ru закрыты JS-проверкой от ботов, открытых наборов о трафике нет, поэтому по МО есть только Telegram ЦБДД.
